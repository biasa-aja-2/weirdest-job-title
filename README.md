One job title, 60 characters at most: the weirdest we could think of. A
real-sounding council role with one hilariously specific twist — an
officer whose whole job is apologising to geese on the council's behalf.

> Head of Apologizing to Geese on Behalf of the Council

## Run it

```sh
python3 main.py
```

The program self-checks the kit's gates (UTF-8, 1–60 characters, one line,
not whitespace-only, no control characters) and refuses to write if any
gate fails, then writes the title to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`) with no trailing newline.
